# Research and citations

These publications describe the motivation, architecture, use cases, and research direction of CausalBench. For exact Python behavior, also consult the [API reference](api.md), which is checked against the package source.

## Start with these resources

- [CausalBench: A Unifying Framework for Benchmarking Causal Learning Models](files/papers/CausalBench_Unifying.pdf) — the full framework, formal model, static and temporal discovery case studies, and reproducibility discussion.
- [CausalBench: Causal Learning Research Streamlined](files/papers/CausalBench_Tutorial.pdf) — the two-page KDD 2025 hands-on tutorial paper.
- [Quickstart notebook](files/CausalBench-Quickstart.ipynb) — the shortest package workflow.

When citing an individual public benchmark run, use the citation metadata and DOI shown by its repository record. Do not substitute a component ID or Run ID for a DOI.
